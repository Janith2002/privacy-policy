# 🔒 Privacy Policy

A simple, hosted **Privacy Policy page** for apps and services that require a publicly accessible privacy policy URL — commonly needed for app store submissions and third-party API approvals.

## 📋 Purpose

This repository hosts a static privacy policy page for use with mobile apps, Telegram bots, or web services that require a privacy policy link.

## 🛠️ Tech Stack

- HTML5
- Static hosting (GitHub Pages compatible)

## 🚀 Usage

The privacy policy is accessible via GitHub Pages at:  
`https://janith2002.github.io/privacy-policy/`

To customize:

```bash
git clone https://github.com/Janith2002/privacy-policy.git
# Edit index.html with your app/service details
```
